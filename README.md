# 恐龙骨架装架设计系统

浏览器端的恐龙骨架装架姿态设计与钢架生成工具。TypeScript + three.js + Vite。

## 启动

```bash
npm install
npm run dev
```

首次打开无数据时自动生成一具两足兽脚类和一具四足蜥脚类骨架,数据保存在 localStorage。

## 页面

| 页面 | 功能 |
| --- | --- |
| 骨架列表 | 骨架增删改、复制、导入导出 JSON,无数据可一键生成示例骨架 |
| 骨骼编辑 | 层级树编辑、关节限位(°)、缺失骨块标记(补件区分色)、触地点/支撑点/IK 链底标记 |
| 姿态设计 | 拖动骨骼走 CCD IK,关节到限位自动卡住并提示;重心实时计算并投影到支撑多边形,失稳标红;姿态方案保存/并排对比;关键帧动画;4K 截图 |
| 钢架生成 | 按当前姿态生成主杆+托架+连杆,杆件避让骨块,杆径按负荷分档,明细导出 CSV |
| 展厅预览 | 展厅场景、三盏展灯(阴影)、观众/儿童/入口/俯瞰视角预设、高清截图 |
| 设置 | 颜色、显示开关、IK 迭代数、钢架间隙、数据管理 |

## 关键设计

- **关节约束**:`clampAngles` 是所有姿态写入的唯一入口,IK 每步分解欧拉角逐轴钳制,任何时刻关节角都在设定范围内
- **IK 性能**:CCD 迭代只重算受影响子树(`updateSubtree`),200 块骨骼拖动保持 60fps
- **重心核对**:重心 = Σmᵢ·pᵢ/Σmᵢ,姿态设计页左栏有逐骨块质量与质心坐标明细表,可手算核对
- **钢架避让**:主杆落地侧移并采样检测与全部骨块胶囊体的干涉,逐级外移直到无碰撞;托架止于骨面留出设定间隙
